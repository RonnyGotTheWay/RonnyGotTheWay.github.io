# ART-Rank Quant（智势量选）

面向 A 股日频研究的可审计量化平台。系统从确定性合成数据开始，依次完成 PIT 数据对齐、特征工程、滚动样本外训练、股票排序、约束组合、回测、API 与研究网站。

> 当前版本仅用于研究、回测和模拟组合，不连接券商实盘，不使用客户/账户/成交明细，也不接入未经授权的商业行情。

> 本目录为便于小组成员查看与复现而发布的源码副本。为遵守行情数据授权并控制仓库体积，未包含本机 `.env`、东方财富历史行情、本地模型产物、依赖目录和构建缓存；请按下方“快速开始”在本机生成合成数据或接入个人获授权的数据源。

## 静态市场两月报告

系统主界面提供最近60个完整交易日的市场两月报告、板块趋势和 ART-Rank Top 10。报告不会自动轮询或触发交易；先完成本地日线更新，再手动发布：

```bash
make weekly-report
# 或复现指定基准日
art-rank weekly-report --as-of 2026-07-22
```

访问 `http://127.0.0.1:3000/weekly-market` 查看两月市场与板块趋势，访问 `/weekly-ranking` 查看全市场和分板块 Top 10。总评分由 65% ART 模型分和 35% 可解释交易经验分组成；触及涨跌停、ST、停牌、低流动性和明显五日下降趋势股票会先被硬性排除。每只入榜股票可显示基于历史五日路径校准的研究参考买入、目标卖出、预期涨幅及止损区间；这些数据不构成交易指令或收益承诺。

## 授权行情与每日快照

当前本机配置使用已获个人研究许可的东方财富行情中心页面及其页面数据接口，无需 Token。每次抓取覆盖沪深京 A 股，证券名称与行情同时校验并进入候选排名。该数据只能保存在本机用于个人研究，不得再分发或盈利使用。

每日收盘后执行：

```bash
make eastmoney-daily
```

命令会追加写入 Raw Parquet、训练准备 Parquet、行数、日期范围和 SHA-256 manifest，供两月报告与 Top 10 使用。

## 快速开始

```bash
make venv
make install
make test
make synthetic
make api
```

前端：

```bash
npm install
npm run dev:web
```

默认 API 只监听 `127.0.0.1:8000`，Web 只监听 `127.0.0.1:3000`。完整架构、数据口径和运维方式见 `docs/`。

## 核心原则

- 所有时间敏感数据同时保留 `event_time`、`available_time`、`ingested_at`。
- 训练只采用 purged walk-forward；预测、模型、组合结果只追加、不覆盖。
- HMM/TFT 作为市场上下文，PatchTST embedding 与 PIT 因子进入 LambdaRank。
- 动态集成只能使用预测日前已经实现的样本外表现。
- T 日收盘信号最早在 T+1 成交。
